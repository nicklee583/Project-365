# Project 365 — V4.2

## External source buttons

The poem, essay, and artwork source links are now rendered as clear CTA buttons:

- **Read the poem**
- **Read the essay**
- **View the artwork**

The source institution appears as quiet attribution text below the button.

The buttons remain external links and open in a new tab.

### Visual treatment
- poem action: maroon;
- essay action: phthalo green;
- artwork action: phthalo-green gradient.

On mobile the action buttons become full width for easier tapping.

## Artwork cleanup

The large decorative **A** in each artwork card was an app-design monogram, not artwork metadata.

It has been removed completely.

Artwork cards now flow directly:

**Artwork → Title → Artist/Culture → Viewing Prompt → View Artwork button**

No content or source URLs were changed.

## Data / state compatibility

No migrations are required.

The following existing local data continues to work unchanged:
- completed days;
- started / in-progress days;
- reflections;
- favorites.

The 365-day production content dataset is unchanged.
