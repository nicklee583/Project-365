# V3 Update Notes

Upload/replace the app source files with this package. Preserve the `.github` folder so GitHub Pages continues to deploy.

After the commit:

1. Open **Actions → Deploy 365 App to GitHub Pages**.
2. Confirm the new run receives a green checkmark.
3. Open the live site and test:
   - write a Day 1 reflection;
   - refresh the page and confirm it remains;
   - mark Day 1 complete;
   - move to Day 2;
   - return to an unfinished day and use **Reset this day**;
   - return home and confirm the completion/in-progress counts update.

Important: reset uses a browser confirmation and only affects the selected day.
