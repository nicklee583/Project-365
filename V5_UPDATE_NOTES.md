# Project 365 — V5 Final Dark Academia Finish

This pass is intentionally aesthetic rather than feature-driven.

## 1. Baskerville typography

The literary hierarchy now uses a Baskerville-first font stack:

`"Baskerville Old Face", Baskerville, "Iowan Old Style", "Palatino Linotype", Palatino, "Book Antiqua", Georgia, serif`

Baskerville is applied to the major titles, guiding questions, work titles, reflection writing, calendar headings and day numerals.

Navigation, controls and metadata remain sans-serif for contrast and legibility.

No font files are bundled with the project. Devices with Baskerville Old Face or Baskerville installed will use it; other devices use close classical serif fallbacks.

## 2. Sharper card geometry

Major reading and journal surfaces now use square editorial edges rather than soft card rounding:
- Home hero
- Poem / Essay / Artwork cards
- Reflection panel
- Completion panel
- Calendar header
- Movement sections

Calendar day cells use only a one-pixel radius.

## 3. Antique-gold favorites

Favorites now use a dedicated antique-gold palette and custom line-star SVG rather than a system star glyph.

Gold is reserved for saved/favorite state so it remains meaningful.

## 4. Subtle rules and texture

The interface now includes:
- a faint woven/paper texture;
- restrained printed rules beside media labels;
- a fine rule after the guiding-question introduction;
- simplified closing ornament;
- fine archival lines inside the Calendar.

The intent is book cloth / printed journal, not faux parchment.

## 5. Calendar refinement

The Calendar has been restyled to feel more like a manuscript index:
- sharper movement sections;
- Roman numeral movement markers;
- quieter day cells;
- phthalo completion markers;
- maroon in-progress markers;
- antique-gold favorite markers;
- simplified state borders;
- Baskerville day numerals;
- more restrained legend and filters.

## Compatibility

No content or URLs were changed.

Existing local state keys remain unchanged:
- completed days;
- started/in-progress days;
- reflections;
- favorites.

The 365-day production dataset is unchanged.
