# Project 365 — V4.3

## Dark-academia link icon refinement

The emoji-style external-link arrow has been removed from all poem, essay, and artwork buttons.

It has been replaced with a custom line-drawn arrow-up-right SVG:
- thin rounded stroke;
- no emoji rendering;
- consistent across browsers and operating systems;
- subtle movement on hover;
- reduced-motion support.

This keeps the source buttons aligned with the darker editorial / dark-academia visual direction.

No content, URLs, completion data, reflections, favorites, calendar state, or production dataset fields were changed.
